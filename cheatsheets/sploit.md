# Чеклист сплойта — шпаргалка

Два контракта: **CookieFarm** (основной стек) и **S4DFarm** (запасной контур,
`farm_client.py`). Связано: [ферма](farm.md), [обходы фиксов](../fixes/bypass-matrix.md).

## CookieFarm (`@exploit_manager`)

- [ ] `from cookiefarm import exploit_manager`, декоратор на функции
- [ ] Сигнатура: `exploit(ip, port, name_service, flag_ids)`
- [ ] Флаги печатать в stdout; декоратор сам режет по regex и сабмитит
- [ ] `flag_ids` — список ID только этой команды/сервиса (может быть dict)
- [ ] Один процесс обходит все команды: не хардкодить IP, `my_team_id` уже
  исключён сервером
- [ ] `-n` = имя сервиса из `config.yml`; порт подставится сам
- [ ] Тест на NOP: `ckc exploit test -e <name> -n <service> -t 30 -W 5`
- [ ] Долгий сплойт → `-P` (process mode), отладка → `-d` не нужен

## S4DFarm (`farm_client.py`)

- [ ] `#!/usr/bin/env python3` первой строкой (shebang обязателен)
- [ ] IP цели из `sys.argv[1]`
- [ ] Флаги в stdout, каждый `print(..., flush=True)`
- [ ] Мусор в stdout допустим (ферма выцепит регуляркой), но лучше не спамить
- [ ] Код возврата не важен, время ограничено (обычно attack_period / волны)
- [ ] Attack data: `ATTACK_DATA_URL`/`_pick_entry` покрывает типовые форматы

## Перед запуском

- [ ] Тест на своём vulnbox (легитимный сервис)
- [ ] Тест на мёртвом IP: сплойт не должен висеть (таймауты!)
- [ ] Тест на уже пропатченной копии: не падать, просто 0 флагов
- [ ] Один сплойт = одна уязвимость (легче отлаживать и чинить)
- [ ] Идемпотентность: повторный запуск не ломает сервис
- [ ] Не деструктурить без нужды (`DROP TABLE`, убийство процессов, флуд)
- [ ] Не светить свои IP/пейлоады, если правила игры это наказывают

## Производительность

- [ ] Параллельность ограничена (пул 4-8 на команду)
- [ ] Таймауты на каждый запрос (2-5 сек) и общий дедлайн сплойта
- [ ] Rate-limit/паузы, чтобы не спамить сервис и чекер
- [ ] Дедуп флагов (в ферме есть, но лучше и в сплойте)

## Стиль

- [ ] Уникальный User-Agent (или рандом из списка), не «python-requests»
- [ ] Логи — в stderr, только флаги — в stdout
- [ ] Флаг печатать целиком и точно (без лишних символов)

## После патчей противника

- [ ] Байпасс: тот же баг другим путём (см. `fixes/bypass-matrix.md`)
- [ ] Проверить, не сломали ли их патчи сплойт (0 флагов = стоп/байпасс)
- [ ] Смотреть улов по сплойтам: мёртвые — чинить или выключать

## Частые ошибки

- Забыл `flush=True` — флаги теряются при kill.
- Нет таймаутов — процесс занимает слот пула, время раунда уходит.
- Захардкожен IP/токен — работает только против одной команды.
- Флаг печатается с мусором — regex фермы не матчится.
- `requests` без `verify=False` на самоподписанных — падает; в CTF обычно
  `verify=False`, но проверь.
