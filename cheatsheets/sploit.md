# Чеклист сплойта — шпаргалка

## Контракт

- [ ] `#!/usr/bin/env python3` первой строкой (shebang обязателен)
- [ ] IP цели из `sys.argv[1]`
- [ ] Флаги в stdout, каждый `print(..., flush=True)`
- [ ] Мусор в stdout допустим (ферма выцепит регуляркой), но лучше не спамить
- [ ] Код возврата не важен, время ограничено (обычно attack_period / волны)

## Перед запуском в ферму

- [ ] Тест на своём vulnbox (легитимный сервис)
- [ ] Тест на мёртвом IP: сплойт не должен висеть (таймауты!)
- [ ] Тест на чужом сервисе, который уже пропатчен: не падать
- [ ] Один сплойт = одна уязвимость (легче отлаживать и чинить)
- [ ] Идемпотентность: повторный запуск не ломает сервис
- [ ] Не трогать чужие данные/не деструктурить без нужды (не вызывать
  `DROP TABLE`, не убивать процессы, не занимать все сокеты)
- [ ] Attack data: формат под текущую борду, `_pick_entry` покрывает типовые

## Производительность

- [ ] Параллельность внутри сплойта ограничена (пул 4-8 на команду)
- [ ] Таймауты на каждый HTTP-запрос (2-5 сек), общий дедлайн
- [ ] Не спамить борду/сервис (rate-limit, паузы между попытками)
- [ ] Повторные флаги не печатать (дедуп в ферме есть, но лучше и в сплойте)

## Стиль

- [ ] Уникальный User-Agent (или рандом из списка) — не «python-requests»
- [ ] Не светить свои IP/пейлоады в открытых полях, если игра это наказывает
- [ ] Логи — в stderr, только флаги — в stdout

## После игры/патчей противника

- [ ] Обход фикса: тот же баг другим путём (см. fixes/README.md — что чинят)
- [ ] Проверить, не сломали ли твой сплойт их патчи (0 флагов = стоп или байпасс)
- [ ] Смотреть, какой сплойт сколько флагов приносит: мёртвые — чинить/выключать

## Частые ошибки

- Забыл `flush=True` — флаги теряются при kill.
- Нет таймаутов — процесс занимает слот пула, время раунда уходит.
- Захардкожен чужой IP/токен — работает только против одной команды.
- Флаг печатается с лишними символами — regex фермы не матчится (полный
  `fullmatch` перед печатью).
- `requests` без `verify=False` на самоподписанных — падает; в CTF обычно
  `verify=False`, но проверь.
