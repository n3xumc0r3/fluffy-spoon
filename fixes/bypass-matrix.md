# Матрица обходов: чем атакуют уже «закрытые» дыры

После любого фикса атакующие пробуют обходы. Прогони свой PoC по списку класса.
Общее: **фикс одной точки ≠ фикс класса** — проверь все эндпоинты, методы,
параметры (GET/POST/JSON/multipart/headers/cookies) и оба сервиса, если их два.

## SQLi (`sqli.md`)

| Обход | Проверка |
|---|---|
| Другой тип кавычек/комментарий | `' OR 1=1--`, `" OR 1=1--`, `) OR 1=1--` |
| Кодировки и двойной декод | `%27`, `%2527`, юникод-апострофы |
| Регистр ключевых слов | `UnIoN SeLeCt`, комментарии `/**/` |
| Слепая/время | `' AND SLEEP(3)--`, `' AND 1=1--` vs `1=2` |
| ORDER BY / LIMIT из ввода | `ORDER BY 1`, `LIMIT 1,999999` |
| LIKE-инъекция | `%`/`_` в LIKE (wildcard) |
| Второй параметр/заголовок | тот же ввод в `X-Forwarded-For`, JSON-полях |
| Числовой контекст | `1 OR 1=1`, `1; DROP` |

## CMDi (`cmdi.md`)

| Обход | Проверка |
|---|---|
| Разделители | `;`, `&&`, `||`, `|`, newline `%0a`, `%0d` |
| Подстановка | `$(id)`, `` `id` ``, `${IFS}`, `$IFS`, `$@` |
| Кавычки/экранирование | `'`, `"`, `\$`, `\\` |
| Слепые символы | `%09`, `%0a` внутри аргумента |
| Windows | `&`, `|`, `^`, `%COMSPEC%` |
| Другой бинарь | `busybox`, `/bin/sh`, `env`, `perl -e` |
| Аргумент, а не shell | если `shell=False` — проверь инъекцию в самом бинаре (например, `tar --checkpoint-action`) |

## Path traversal (`path-traversal.md`)

| Обход | Проверка |
|---|---|
| Двойной декод | `%252e%252e%252f`, `%2e%2e/`, `..%2f`, `..%5c` |
| Абсолютный путь | `/etc/passwd` вместо `../../etc/passwd` |
| Симлинк | `ln -s / /srv/app/static/root` |
| Unicode/overlong | `%c0%ae%c0%ae/`, `%uff0e%uff0e/` |
| NUL-байт (старые стеки) | `file.php%00.png` |
| Windows | `..\`, `..%5c`, `C:\`, `\\?\` |
| ZIP/tar slip | `../evil`, абсолютные члены, симлинк в архиве |

## SSTI (`ssti.md`)

| Обход | Проверка |
|---|---|
| Другие движки | Jinja2, Twig, Freemarker, Velocity — payload под каждый |
| Конкатенация/фильтры | `{{7*7}}`, `{{7*'7'}}`, `{{ 'a'|upper }}` |
| Sandbox escape | `{{ self.__init__.__globals__ }}`, `{{ get_flashed_messages.__globals__ }}`,
`{{ cycler.__init__.__globals__.os.popen('id').read() }}` |
| Обёртки | `attr`, `|attr('__class__')`, `__getitem__` |
| Шифрование/кодирование | payload в base64, если сервис декодирует перед рендером |

## SSRF (`ssrf.md`)

| Обход | Проверка |
|---|---|
| IP-трюки | `127.0.0.1`, `0177.0.0.1`, `2130706433`, `[::1]`, `0.0.0.0` |
| DNS | `localhost.`, своя A-запись → 127.0.0.1, rebinding (два ответа) |
| Redirect | внешний URL 302 → внутренний (проверь `allow_redirects`) |
| Userinfo | `http://expected@127.0.0.1/` |
| Схемы | `file://`, `gopher://`, `dict://`, `ftp://` |
| Заголовки | `Host: 127.0.0.1`, `X-Forwarded-Host` |

## Десериализация (`deserialization.md`)

| Обход | Проверка |
|---|---|
| Другой формат | pickle, yaml, marshal, PHP `unserialize`, Java `ObjectInputStream` |
| Кодировка | base64/gzip/hex вокруг payload |
| Другой протокол pickle | protocol 0..5 |
| Gadget-цепочки | библиотеки в сервисе (requests, Django, Flask) |
| YAML-теги | `!!python/object/apply:os.system` |

## Auth/IDOR/JWT (`auth.md`)

| Обход | Проверка |
|---|---|
| JWT `alg` | `none`/`None`/`nOnE`, `HS256` с публичным ключом (confusion) |
| `kid`/`jku`/`x5u` | path traversal в `kid`, подмена JWKS URL |
| Пустой/слабый секрет | брут по словарю из репо/`.env` |
| IDOR | `id±1`, UUID из другого эндпоинта, числовой перебор без авторизации |
| Mass assignment | передать `role=admin`, `is_admin=true`, `team_id` в регистрации |
| Сессия | фиксация, отсутствие `HttpOnly/Secure`, cookie без подписи |
| Сброс пароля | токен без привязки к юзеру, предсказуемый код |

## Крипто (`crypto.md`)

| Обход | Проверка |
|---|---|
| ECB | одинаковые блоки (`A`*16 + данные) |
| Padding oracle | побайтовая подмена последнего блока, разница ошибок |
| IV reuse/фиксированный IV | XOR двух шифртекстов |
| Слабый PRNG | `random` вместо `secrets`, время как seed |
| Утечка ключа | ключ в репо/конфиге/логе/ошибке |
| Сравнение | не constant-time (`==`) для MAC/токенов |

## Загрузка (`upload.md`)

| Обход | Проверка |
|---|---|
| Расширения | `.phtml`, `.php5`, `.php7`, `.phar`, `.htaccess` |
| Двойное расширение | `x.php.png`, `x.png.php`, `x.php%00.png` |
| Content-Type | подмена MIME, `image/png` при PHP-контенте |
| Magic bytes | polyglot GIF+PHP |
| Симлинк/архив | zip slip, symlink в tar |
| Исполнение | загрузка в web-root, `.htaccess` с `AddType` |

## XXE (`xxe.md`)

| Обход | Проверка |
|---|---|
| Кодировка документа | UTF-16 → фильтр по `<` не срабатывает |
| Параметрические сущности | `%foo;` во внешнем DTD |
| OOB-exfil | внешний DTD + HTTP/FTP-запрос |
| XInclude | `<xi:include href="file:///etc/passwd">` |
| Другие парсеры | SOAP, SVG, DOCX/XLSX (zip+xml), SAML |

## ReDoS (`redos.md`)

| Обход | Проверка |
|---|---|
| Другой вход | `^(a|aa)+$`, длинные повторы, вложенные группы |
| Место применения | другой параметр/заголовок/JSON-поле |
| Таймаут | выстави лимит времени на regex (библиотека) |

## Гонки (`race-condition.md`)

| Обход | Проверка |
|---|---|
| Параллельность | 20-50 одновременных запросов |
| Задержки | 10-100 мс между проверкой и записью |
| Несколько эндпоинтов | apply/cancel, buy/sell, deposit/withdraw |
| Частичный unique | два «одновременных» INSERT с разными ключами |

## HTTP-инъекции (`http-injection.md`)

| Обход | Проверка |
|---|---|
| CRLF | `%0d%0a`, `%0a`, двойной декод `%250d%250a` |
| Юникод-переводы | `%e5%98%8a%e5%98%8d` |
| Open redirect | `//evil`, `https:evil`, `/\evil`, `?next=` |
| XSS-контекст | атрибут, JS-строка, `<script>`, `</title>` |
| Заголовок | `Content-Disposition` с именем файла из ввода |

## NoSQL (`nosql.md`)

`$ne`, `$gt`, `$regex`, `$where`, `$in`, вложенные объекты, массивы в
form-декодерах, type-check bypass через `null`/числа.

## Format string (`format-string.md`)

`{0.__class__}`, `{0.__dict__}`, `{:>99999999}`, `%n`, `%7$n`, `%s%s%s%s`.

## Source disclosure (`source-disclosure.md`)

`.git/config`, `.env`, `.svn/entries`, `%2e`-обходы, `.map`, `/actuator/*`,
`/console`, `/__debug__/`, бэкапы с другими расширениями.

## Регресс после патча (обязательно)

1. Старый PoC → закрыт (401/403/404/400, без данных).
2. Обходы из таблицы класса → закрыты.
3. Легитимный сценарий чекера → работает (симулятор/борда).
4. Все точки класса закрыты: все эндпоинты, методы, парсеры, второй сервис.
5. `watch_status.py` — стабильно UP 1-2 тика, без MUMBLE.
6. Firegex-фильтр не мешает чекеру; после фикса кода — снять.
7. Свежий снапшот + коммит с описанием фикса и PoC.
